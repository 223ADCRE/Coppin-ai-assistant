# 🎓 Coppin AI Assistant

An AI-powered chatbot designed to help students at Coppin State University get instant answers about admissions, programs, financial aid, and campus life.

## 🚀 Features
- 🤖 AI chatbot powered by OpenAI
- 📚 Retrieval-Augmented Generation (RAG)
- 🔍 Vector search using Astra DB
- 🌐 Real-time web data scraping
- 💬 ChatGPT-like interface (Next.js)

## 🛠 Tech Stack
- Next.js (Frontend + API)
- OpenAI API (LLM + Embeddings)
- Astra DB (Vector Database)
- Puppeteer (Web scraping)
- LangChain (optional utilities)
